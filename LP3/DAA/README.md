# DAA: Design and Analysis of Algorithms

LP3 Group A. The code files contain only code. The problem statement,
approach, complexity and viva prep for each assignment are in its `.md` file.

| # | Assignment | Write-up | Code |
| --- | --- | --- | --- |
| 1 | Fibonacci numbers, non-recursive and recursive, with step count | `1_Fibonacci.md` | `1_Fibonacci.cpp`, `1_Fibonacci.py` |
| 2 | Huffman Encoding using a greedy strategy | `2_HuffmanEncoding.md` | `2_HuffmanEncoding.cpp`, `2_HuffmanEncoding.py` |
| 3 | Fractional Knapsack using a greedy method | `3_FractionalKnapsack.md` | `3_FractionalKnapsack.cpp`, `3_FractionalKnapsack.py` |
| 4 | 0-1 Knapsack using dynamic programming | `4_ZeroOneKnapsackDP.md` | `4_ZeroOneKnapsackDP.cpp`, `4_ZeroOneKnapsackDP.py` |
| 4 | 0-1 Knapsack using branch and bound | `4_ZeroOneKnapsackBranchAndBound.md` | `4_ZeroOneKnapsackBranchAndBound.cpp`, `4_ZeroOneKnapsackBranchAndBound.py` |
| 5 | N-Queens with the first Queen placed, using backtracking | `5_NQueens.md` | `5_NQueens.cpp`, `5_NQueens.py` |

## How to run

```bash
g++ -std=c++17 1_Fibonacci.cpp -o fib && ./fib
python 1_Fibonacci.py
```

The same pattern works for every file. Each program asks for its input.
