LP3 Group C. Assignments 1, 2 and 5 are write-ups only. Assignments 3 and 4
have a Solidity contract (code only) and a write-up with the explanation,
deployment steps and viva questions.

## How to run

Open `remix.ethereum.org`, paste a `.sol` file, compile with a `0.8.x`
compiler, and deploy on **Remix VM**. Each write-up lists the steps.
