# BT: Blockchain Technology (LP3, Group C)

Covers assignments 1-5 of the Group C practical list. The mini project (item 6) is out of scope here — handled separately.

There is no browser, MetaMask, Ethereum node, or internet access in this environment, so nothing here was actually installed or deployed. Each file is a thorough instructional write-up: steps, full Solidity code, gas/fee behavior explained from Ethereum's documented gas model, Mermaid diagrams in place of real screenshots, and a "Key Terms" + "Viva Questions" recap at the end.
